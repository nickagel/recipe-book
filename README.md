# recipe-book

Static recipe search site for GitHub Pages (Settings → Pages → deploy from branch, root folder).

## Adding a recipe

1. Create `recipes/<slug>/` with `description.yml`, `measurements.csv`, `instructions.csv` (CSV files have a header row).
2. Run `make index` to rebuild `recipes/index.json`.
3. Optional photos: put them in `recipes/<slug>/images/` and list the filenames in `description.yml`, e.g. `images: [finished.jpg, step-2.jpg]`.

The `url` in `description.yml` is not shown on the site; it records the source to pull recipe updates from.

With Claude Code, the `add-recipe` skill (`.claude/skills/add-recipe/SKILL.md`) handles this from a URL or pasted text.

## Project layout

- `index.html`, `app.js`, `style.css`: the site. It has no build step and no dependencies. Recipes load from `recipes/` at runtime, and each one is linked as `#/<slug>`. While recipes load, a top progress bar and placeholder cards are shown. Each recipe page has a Share button that copies its URL to the clipboard.
- `favicon.svg`: the site icon (a chef hat).
- `recipes/index.json`: sorted list of recipe slugs, generated by `make index`.
- `scripts/format_data.py`: normalizes recipe CSVs and JSON files.
- `.github/workflows/`: CI checks that fail if `make format` or `make index` would change anything.

## Make targets

| Command | Description |
| --- | --- |
| `make start` / `make stop` / `make restart` | Local server at http://localhost:8000 (`PORT=` to change) |
| `make index` | Rebuild `recipes/index.json` |
| `make install` | Create `.venv` and install formatters from `requirements.txt` |
| `make format` | Format YAML, CSV, JSON, JS and HTML |

Requires Python 3.15 (see `.python-version`). Run `make format` and `make index` before committing.
